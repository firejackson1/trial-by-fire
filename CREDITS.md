# Credits

Trial by Fire exists because of the work of these projects and people. Thank you.

## Operating system

- **[LineageOS](https://lineageos.org)**: Trial by Fire is built from LineageOS 24.0 (the `lineage-24.0` branches), including its build system, settings, and apps (Aperture, Etar, Jelly, Glimpse, Recorder, Twelve and others). Source: <https://github.com/LineageOS>
- **[Android Open Source Project](https://source.android.com)**: the Android 17 platform underneath LineageOS.

## Kernel and device

- **[amazon-mt8183-devs](https://github.com/amazon-mt8183-devs)**: the `android_kernel_amazon_mt8183` kernel tree for the MT8183 Fire tablets, including **bengris32**'s `trona` defconfig work, which the kernel patches here build on.
- **Amazon** and **MediaTek**: the stock Fire OS vendor software this ROM runs on. No proprietary files are redistributed here.
- **TeamWin Recovery Project (TWRP)**: the recovery used to install the system image.

## Optional add-ons

- **[MindTheGapps](https://gitlab.com/MindTheGapps/vendor_gapps)**: the Google apps package documented in `docs/GAPPS.md` (not included in the ROM or in this repository).
- **[scrcpy](https://github.com/Genymobile/scrcpy)** by Genymobile: used during development for screen mirroring.
